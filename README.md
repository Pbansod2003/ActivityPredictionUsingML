# Activity Prediction Using Machine Learning

A beginner-friendly Python project that predicts **Play** or **Study** from weather and temperature using a Decision Tree Classifier.

## Files
- `activity_prediction.py` — corrected Python program
- `data.csv` — dataset converted from the supplied Excel file; values are cleaned
- `mini_project_report.docx` — project report supplied with the project
- `requirements.txt` — required Python packages

## Requirements
Install Python 3.x, then open a terminal in this folder and run:

```bash
python -m pip install -r requirements.txt
```

## Run the project

```bash
python activity_prediction.py
```

When prompted, enter `Sunny`, `Rainy`, or `Cloudy`, followed by a numeric temperature (for example, `30`).

## Important note
This is an educational demonstration. Predictions depend on the small sample dataset and are not guaranteed real-world recommendations.
